# 🎬 ইউনিভার্সাল প্রিমিয়াম ভিডিও ডাউনলোডার (Universal Premium Video Downloader)

একটি চমৎকার, আধুনিক এবং হাই-পারফরম্যান্স ওয়েব-ভিত্তিক ভিডিও ডাউনলোডার, যা যেকোনো প্ল্যাটফর্ম (ইউটিউব, ফেসবুক, টুইটার, ইনস্টাগ্রাম, টিকটক ইত্যাদি) থেকে **৮কে (8K) রেজোলিউশন** পর্যন্ত ভিডিও ডাউনলোড এবং উচ্চ মানের **MP3** অডিও এক্সট্র্যাক্ট করা সমর্থন করে। এটি **Node.js**, **Express**, এবং **yt-dlp** দ্বারা চালিত।

🌐 **[English Version is available here (ইংরেজি সংস্করণ এখানে)](README.md)**

---

## ✨ বৈশিষ্ট্যসমূহ (Features)

- **🚀 ডুয়াল ইঞ্জিন বুটস্ট্র্যাপিং**: অ্যাপ্লিকেশনটি চালু করার সাথে সাথেই স্বয়ংক্রিয়ভাবে `yt-dlp` এর সর্বশেষ বাইনারি সংস্করণ ডাউনলোড করে নেয়। কোনো ম্যানুয়াল সেটআপের প্রয়োজন নেই!
- **🎞️ আল্ট্রা এইচডি রেজোলিউশন সাপোর্ট**: সোর্স ভিডিওর ওপর ভিত্তি করে এটি **8K, 4K, 2K, 1080p, 720p, 480p, 360p** রেজোলিউশনে ডাউনলোড করা সমর্থন করে।
- **⚡ রিয়েল-টাইম প্রোগ্রেস বার (SSE Stream)**: সার্ভার-সেন্ট ইভেন্টস (SSE) প্রযুক্তি ব্যবহার করে রিয়েল-টাইমে ডাউনলোডের পার্সেন্টেজ, ডাউনলোডের গতি, ফাইলের সাইজ এবং আনুমানিক সময় (ETA) সরাসরি ব্রাউজার ড্যাশবোর্ডে প্রদর্শন করে।
- **🎵 হাই-কোয়ালিটি অডিও এক্সট্র্যাকশন**: যেকোনো ভিডিও থেকে অডিও আলাদা করে তা সরাসরি উচ্চ-মানের **MP3** ফর্ম্যাটে রূপান্তর করতে পারে।
- **🔄 ভিডিও রোটেশন (ঘোরানো)**: ডাউনলোড করার পর ভিডিওটিকে সরাসরি ৯০ ডিগ্রি ক্লকওয়াইজ (ডান দিকে) বা কাউন্টার-ক্লকওয়াইজ (বাম দিকে) ঘোরানোর সুবিধা (FFmpeg ইন্টিগ্রেশন ব্যবহার করে)।
- **📂 দ্রুত ফোল্ডার অ্যাক্সেস**: মাত্র এক ক্লিকে ব্রাউজার ড্যাশবোর্ড থেকেই ডাউনলোড ফোল্ডারটি ওপেন করার সুবিধা।
- **🎨 গর্জিয়াস গ্লাসমরফিজম ডার্ক থিম UI**: সুন্দর ডিজাইন করা ডার্ক-থিম ড্যাশবোর্ড, রেসপন্সিভ কার্ড, গ্লোয়িং অ্যাকসেন্ট এবং চমৎকার মাইক্রো-অ্যানিমেশন।

- **ফ্রন্টএন্ড (Frontend)**: HTML5, Vanilla CSS3 (Custom Glassmorphism), Modern JavaScript
- **ব্যাকএন্ড (Backend)**: Node.js, Express.js
- **ডাউনলোডার ইঞ্জিন (Engine)**: `yt-dlp` (স্বয়ংক্রিয়ভাবে পরিচালিত)
- **মিডিয়া প্রসেসিং (Media Processing)**: `FFmpeg` (উচ্চ রেজোলিউশনের ভিডিও-অডিও মার্জ করতে এবং ভিডিও ঘোরানোর জন্য এটি অত্যন্ত প্রয়োজনীয়)

## 🚀 যেভাবে শুরু করবেন (Getting Started)

আপনার কম্পিউটারে ডাউনলোডারটি সেটআপ এবং রান করতে নিচের সহজ ধাপগুলো অনুসরণ করুন:

### ১. পূর্বশর্ত (Prerequisites)

- **Node.js**: আপনার কম্পিউটারে Node.js (ভার্সন ১৬ বা তার বেশি) ইনস্টল করা থাকতে হবে। [Node.js ডাউনলোড করুন](https://nodejs.org/)
- **FFmpeg** (সুপারিশকৃত): আল্ট্রা-হাই-ডেফিনিশন ভিডিওর সাথে অডিও মার্জ করার জন্য এবং ভিডিও ঘোরানোর জন্য আপনার সিস্টেমে FFmpeg ইনস্টল করা থাকতে হবে এবং এটি সিস্টেম পাথ এনভায়রনমেন্ট ভেরিয়েবলে যুক্ত থাকতে হবে।
  - *Windows*: `winget install Gyan.FFmpeg` কমান্ডের সাহায্যে অথবা অফিসিয়াল ওয়েবসাইট থেকে ডাউনলোড করে ইনস্টল করতে পারেন।
  - *macOS*: `brew install ffmpeg`
  - *Linux*: `sudo apt install ffmpeg`

### ২. ইনস্টলেশন (Installation)

প্রথমে রিপোজিটরিটি আপনার কম্পিউটারে ক্লোন করুন:
```bash
git clone https://github.com/Souravsanyal1/download-any-video-for-free.git
cd download-any-video-for-free
```

প্রয়োজনীয় npm প্যাকেজগুলো ইনস্টল করুন:
```bash
npm install
```

### ৩. অ্যাপ্লিকেশন রান করা (Run the Application)

সার্ভারটি চালু করতে নিচের কমান্ডটি রান করুন:
```bash
npm start
```
সার্ভারটি চালু হওয়ার পর এটি স্বয়ংক্রিয়ভাবে নিচের কাজগুলো করবে:
1. লোকাল `./bin` ডিরেক্টরিতে `yt-dlp` আছে কিনা তা পরীক্ষা করবে। না থাকলে GitHub থেকে **সর্বশেষ সংস্করণটি স্বয়ংক্রিয়ভাবে ডাউনলোড** করে নেবে।
2. আপনার সিস্টেমে `FFmpeg` ইনস্টল করা আছে কিনা তা পরীক্ষা করবে।
3. আপনার ডিফল্ট ব্রাউজারে এই লিংকে চলে যাবে: **`http://localhost:3000`**।

## ⚙️ যেভাবে এটি কাজ করে (How it Works)

1. **মেটাডেটা সংগ্রহ**: যখন আপনি কোনো ভিডিও লিংক পেস্ট করে "Fetch Details" এ ক্লিক করেন, তখন ব্যাকএন্ডে `yt-dlp --dump-json` কমান্ড রান করে ভিডিওর টাইটেল, ডিউরেশন, থাম্বনেইল, ভিউ কাউন্ট এবং ডাউনলোডের জন্য উপলব্ধ রেজোলিউশনগুলো সংগ্রহ করা হয়।
2. **কোয়ালিটি ও ফরম্যাটিং অপশন**: সার্ভার চেক করে দেখে সিস্টেমে `FFmpeg` ইনস্টল আছে কিনা। ইনস্টল থাকলে এটি হাই-কোয়ালিটি ভিডিও ও অডিও ট্র্যাক আলাদা ডাউনলোড করে মার্জ করে। ইনস্টল না থাকলে সরাসরি মার্জ করা সাধারণ ভিডিও ডাউনলোড করে।
3. **রিয়েল-টাইম প্রোগ্রেস**: ডাউনলোড চলার সময় সার্ভার `yt-dlp` এর স্টDOUT রিড করে রেগুলার এক্সপ্রেশন (regex) দিয়ে পার্সেন্টেজ, স্পিড ও ইটিএ (ETA) আলাদা করে। এরপর সার্ভার-সেন্ট ইভেন্টস (`/api/progress`) ব্যবহার করে সরাসরি ব্রাউজার ড্যাশবোর্ডে রিয়েল-টাইম আপডেট পাঠায়।
4. **পোস্ট-ডাউনলোড প্রসেসিং**: যদি ভিডিও ঘোরানোর অপশন সিলেক্ট করা থাকে, তবে ডাউনলোড শেষ হওয়ার পর ব্যাকএন্ডে একটি সেকেন্ডারি `FFmpeg` প্রসেস রান করে ভিডিওটি ঘুরিয়ে নেওয়া হয়।
